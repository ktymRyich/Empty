# ⛰️ マウンテンエリア（叩き台）

Go Vacation のマウンテンリゾート想定。**温帯の緑の山岳アウトドア・アドベンチャー**。
スノー（雪の高峰）とも、マリン（南国）とも差別化：みずみずしい緑・森・渓谷・川。
← [[areas/_index]]

## 区画（サブゾーン）
1. **ビジターセンター/ロッジ（受付ハブ）** — ウッディでモダンな建物。自転車・馬・
   バギーのレンタル、トレイルの起点。
2. **渓谷と川** — 急流のラフティング／カヤック。奥の滝・湖から流れ下る。
3. **深い森＆キャンプ場** — トレイル、ジップライン、テントサイト。
4. **高原の草原** — 乗馬、熱気球、マウンテンバイク。開けた見晴らし。
5. **岩壁** — ロッククライミング。
6. **滝と湖** — 釣り、ボート、水遊び。
7. **吊り橋＆展望台** — 渓谷をまたぐ長い吊り橋、ハンググライダー発射。
8. **隠れた谷／洞窟** — 宝箱、秘密ルート。

## 遊び / アクティビティ
ラフティング、カヤック、乗馬、マウンテンバイク、バギー／ATV、ロッククライミング、
ジップライン、ハンググライダー、熱気球、釣り、ハイキング、洞窟探検。

## 乗り物 / 移動
馬・マウンテンバイク・バギー（陸）、カヤック／ラフト（川）、ハンググライダー・熱気球（空）。

## 建築トーン
ウッディだが**現代的・清潔**なロッジ／ビジターセンター。和の伝統建築は不使用。

## 収集 / 秘密 / 生き物
隠れた谷・洞窟の宝箱、展望台・吊り橋の写真スポット。鹿・リス・野鳥・キツネ。

## 追加提案（検討用）
アーチェリー場、ツリーハウスの休憩所、ナイトキャンプ（焚き火・星空）、
川の上流から下流へ下る一連のラフティングコース、気球で島を一望。
