# ❄️ スノーエリア

雲の上まで届く高山リゾート。**ふもと（賑わい）→ 中腹（開発）→ 上部（無人の岩稜）
→ 山頂** と高度で表情が変わる。日本のスキー場ベース＋バブル期の華やかさ。← [[areas/_index]]

## 区画（サブゾーン・高度順）
1. **ふもと** — 大きなリゾートホテル群・お土産屋・レストラン。リフト/ゴンドラ乗り口、
   **ヘリポート（上空・山頂へ）**、**Go Vacation 風の屋外受付**。賑わうハブ。
2. **ゲレンデ** — 広い斜面でスキー/スノボ/そり。スノーパーク（ジャンプ台・ハーフパイプ）。
3. **中腹** — 人の手が入った開発エリア。ふもとより小さめのホテル・お土産・レストハウス、
   展望テラス、リフト中間駅。バブル期の華やかさ。
4. **森林エリア** — 雪の木立。ポツンと一軒のコテージ。スノーモービルのトレイル。
5. **凍結湖** — アイススケート、アイスフィッシングの小屋。
6. **上部・岩稜** — **雲の上**。岩肌の急斜面、ゴツゴツした岩、上級者向け、足元に雲海。
7. **秘密の洞窟ルート** — 岩陰の隠し入口。氷柱の洞窟、宝箱の気配。
8. **山頂** — 360度パノラマ、パラグライダー/ハンググライダー発射台、ヘリ発着、展望。

## 遊び / アクティビティ
スキー、スノボ、スノーモービル、そり／リュージュ、スノーラフティング、アイススケート、
アイスフィッシング、雪合戦、犬ぞり、パラグライダー、アイスクライミング（上部）。

## 乗り物 / 移動
リフト・ゴンドラ（上り）、スノーモービル、そり、**ヘリで山頂へ**、
**パラグライダーで一気に下界へ**。

## 建築トーン
ふもと/中腹のホテルは**バブル期（80年代）の華やかなリゾート**。受付は Go Vacation 風の
屋外パビリオン。上部・山頂は**無人で手つかずの岩肌**。和の旅館/温泉建築は不使用。

## 収集 / 秘密 / 生き物
秘密の洞窟ルートの宝箱、山頂・展望テラスの写真スポット。雪うさぎ・キツネ・ライチョウ。

## 追加提案（検討用）
ナイトゲレンデ（ライトアップ）、犬ぞりコース、中腹ホテル屋上の**温水プール**（湯気・モダン。
※伝統温泉ではない）、雪洞（イグルー）カフェ、山頂展望台。
