## 全エリア共通システム（Go Vacation の核 ＝ 忘れがちな要点）
- **乗り物での自由移動が遊びの中心**：各エリアに乗れる乗り物（ジェットスキー/
  バギー/馬/グライダー/スノーモービル/そり 等）。移動そのものが楽しい。
- **収集・発見**：隠し宝箱・スタンプ・写真スポット・「?」マーカー・チャレンジが点在。
  探索の動機づけ。
- **スポット起動型アクティビティ/ミニゲーム**（バレーコート、ジャンプ台など）。
- **受付/ロビーが各リゾートのハブ**（移動・アクティビティの起点）。
- **ペット同行＆野生動物**との触れ合い。
- **昼夜・天候の変化**、フォトスポット。
- **エリア間はシームレスに往来**。乗り物が境界を繋ぐ（例：海→サンゴ礁→深海、
  雪山頂→パラグライダーで下界）。

## 各エリアの出力フォーマット
**1エリア＝上から見た一枚絵（俯瞰の全体図）**を基本とする。区画を空間的に矛盾なく
配置（海沿い→内陸、雪山は高度で同心円 等）して「破綻しない」レイアウトにする。
個別シーンの vignette プロンプトは各 doc の「細部参照用」に残す。

**スケール感を出すコツ（カワウィー島級の広さ）**:
- 「ミニチュア・ジオラマ」「ティルトシフト」は**使わない**（小さく箱庭化する）。
- 「広大」「探索しがいのある大きなオープンワールド」「高い空からの広角の俯瞰」
  「各エリアの間にたっぷり余白」「奥行きと大気遠近（霞）」「長い小道」を入れる。
- もっと横幅が欲しければ比率を 21:9 のパノラマに。建物は土地に対して小さめに。
