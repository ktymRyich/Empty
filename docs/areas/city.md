# 🏙️ シティエリア（叩き台）

Go Vacation のシティリゾート想定。**海に面した現代的な日本の都市リゾート**。
ストリートスポーツ＆アミューズメント中心。和の伝統要素は不使用。← [[areas/_index]]

## 区画（サブゾーン）
1. **駅前広場＆メインストリート（ハブ・商業）** — デフォルメのビル、カフェ、店、
   行き交う小さな日本人。アクティビティの起点。
2. **遊園地** — 観覧車、ジェットコースター、各種アトラクション。
3. **スポーツコンプレックス** — スタジアム、テニス、バスケ、サッカー。
4. **ウォーターフロント／港** — マリーナ、遊歩道、夜景。
5. **スケートパーク＆ストリート** — スケボー、BMX、インライン、ストリートリュージュ。
6. **ゴーカート・サーキット** — 周回コース。
7. **高層ビル街** — 屋上、ヘリポート、パルクール。
8. **都市公園** — 緑、噴水、夜のイルミネーション。

## 遊び / アクティビティ
スケボー、BMX、インライン、ストリートリュージュ、ゴーカート、テニス、バスケ、
サッカー、ボウリング、ダンス、セグウェイ、パルクール、ゲームセンター、買い物。

## 乗り物 / 移動

**城・提灯・神社・伝統建築は不使用**。看板は文字を入れない（記号・色面でそれっぽく）。

## 収集 / 秘密 / 生き物
