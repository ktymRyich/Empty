# 🌊 マリンエリア

Go Vacation のマリンリゾートを強く意識。南国の海＋自然探索。海の遊びから、
ジャングル・遺跡探検まで“一続き”の冒険にする。← [[areas/_index]]

## 区画（サブゾーン）
1. **メインビーチ** — 砂浜、パラソル、ビーチバレー、桟橋とマリーナ。浜辺の
   **インフォメーション施設は現代的・近未来的でモダンに**（白基調・曲線ガラス、
   Go Vacation の受付役）。
2. **内湾・ラグーン** — 穏やかな入り江。初心者向けの遊泳・シュノーケル・カヤック。
3. **海に面した洞窟** — 小舟で入る。青く光る水、宝箱の気配。
4. **すごく浅い川・マングローブ** — 足首ほどの透明な浅瀬、水遊び、小魚やカニ。
5. **ジャングル** — 蔓・ジップライン・丸太橋、鳥やサル、遺跡への小道。
6. **崖と滝** — 崖の下の岩場と滝つぼ、崖上はクリフダイビング。
7. **南国の古代遺跡** — 蔦の絡む石造神殿、仕掛けと宝（※和の城/神社ではない南洋遺跡）。
8. **岬の灯台＋沖のサンゴ礁** — ランドマーク、パラセーリング発射、**深海エリアへの導線**。

## 遊び / アクティビティ
ジェットスキー、バナナボート、サーフィン、シーカヤック、スキューバ／シュノーケル、
釣り、ビーチバギー（砂浜）、パラセーリング／パラグライダー、ビーチバレー、
クリフダイビング、洞窟・遺跡探検。

## 乗り物 / 移動
ジェットスキー・シーカヤック・バナナボート・ビーチバギー・パラグライダー。
沖のサンゴ礁からスキューバで **深海エリア** へ接続。

## 建築トーン
浜の施設は**モダン／近未来**（白・ガラス・曲線・清潔感）。遺跡は南洋の石造（蔦・苔）。

## 収集 / 秘密 / 生き物
隠し宝箱（洞窟・遺跡）、写真スポット（灯台・崖上）、タイドプールの生物観察。
イルカ・ウミガメ・カニ・熱帯魚・南国の鳥・サル。

## 追加提案（検討用）
ナイトビーチ（花火）、沖のサンゴ礁ダイブ＝深海への入口、パラセーリングで島一望、
バナナボート/ジェットスキーの周回コース。
