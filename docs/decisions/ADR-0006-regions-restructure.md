# ADR-0006 エリア構成の刷新（季節を廃止し、リゾート＋ファンタジー区画へ）

## 文脈
初期は「春夏秋冬＋中央火山」の四季フレーミングだったが、Go Vacation のような
“性格の違うリゾートを巡る”体験にしたい、という方針に変更。

## 決定
**季節の概念は廃止**。島のエリアを以下に再定義する。
- コア4（Go Vacation 由来）: 🌊 **マリン** / ❄️ **スノー** / ⛰️ **マウンテン** / 🏙️ **シティ**
- 中央の主役: 🌋 **火山・カルデラ**
- 追加のファンタジー区画: 🚀 **宇宙** / 🌊 **深海**

## トーン / ルール（全エリア共通）
- **「日本人が思い浮かべる明るいリゾート」**。海外リゾート的な憧れ感＋清潔感。
- 都市・スキー場は**現代の日本ベース**。旅行者は**日本人**。
- **和の伝統要素（城・桜・田園・提灯・神社・温泉旅館など）は不使用**。
- ローポリ・トゥーン、明るく陽気、写実にしない。

## 影響
- 各エリアは「区画（サブゾーン）＋遊び＋乗り物＋ランドマーク＋収集/秘密」で設計する。
  → [[areas/_index]]、[[areas/marine]]、[[areas/snow]]
- コードの World/Region 抽象はそのまま使える（エリア名と中身の差し替えのみ）。
- 未反映: `island-vacation/PLAN.md` と GitHub Issue #4〜#6（旧「夏/秋/冬地域」）は
  この新構成へ要更新（TODO）。
